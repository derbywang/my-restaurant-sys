# 7．お客様に返金するとき（案：店長の確認待ち）

> **いまの状態（2026-11-21）：レジの画面には「返金」「返品」のボタンはありません。** この頁は、**システムの画面ではなく、人の手順** で返金するときのやり方です。「レジで返金できます」とは読まないでください。

## 1．だれが、どこでするか

| こと | だれ | どこで |
|---|---|---|
| 返金していいか決める | **店長**（いないときは、店長に電話して決めてもらいます） | その場 |
| お客様にお金を返す | **レジ担当**（店長の OK のあと） | レジ（引き出し） |
| システムに返金を記録する（返品伝票を作る） | **システムの担当**（管理者） | 管理の画面（Desk）。**レジ担当・ホールの画面ではできません** |

- **ホールは返金しません。** お客様から言われたら、レジ担当か店長を呼びます。
- 合算した伝票（会計合算）で支払い済みのときは、**店員は店長を呼ぶだけ** です。システムの記録は、システムの担当が管理の画面で、合算した **2 枚の伝票それぞれに** 返品伝票を作ります。

## 2．最初にすること（お金を返す前）

1. **お客様に少し待っていただき、店長を呼びます。** 自分だけで決めません。
2. **何を返すのか確認します：** どの伝票か（伝票番号、テーブル、時間）、いくらか、なぜか（理由）。
3. **支払い方法を確認します：**
   - **現金で払った** → 現金で返します（下の 3）。
   - **カード・PayPay・楽天ペイで払った** → **現金では返しません。** 決済端末（楽天ペイの端末）の返金・取消しの操作を店長がします。【店で決める：端末の操作は、加盟店の契約を確認してから】
4. **返金メモ**（「6．紙で続ける手順」の「5．お金の記録（様式 C：入金メモ）」と同じ要領で書く紙。1 件ごとに 1 行、時刻・金額・支払方法を書きます）に、日付・時間・伝票番号・テーブル・金額・理由・受け取った人の確認・返した人と OK を出した店長の名前を書きます。

## 3．現金で返すとき（レジの引き出し）

1. **レジの画面の「引き出しを開ける」を押します。**（返金のためにお金を出すときは、これを使います。押すたびに記録が残ります。ボタンが出るのは、レジ担当と店長だけです。ホールの画面には出ません）
2. 返金メモの金額を、お客様の前で数えて返します。
3. **領収書（小票）を回収します：** お客様がレシートを持っているなら **受け取って、返金メモに留めます**（捨てません。税金の控えとして取っておきます）。持っていないときは、返金メモに「領収書なし」と書きます。
4. **収入印紙を貼った領収書** のときは、印紙が貼ってあるまま回収して、返金メモに留め、店長に渡します。
5. **新しい小票は印刷しません。** システムには「返金の小票」はありません。お客様に何か渡すときは、返金メモの控えを手書きでわたします。【店で決める】

## 4．そのあとシステムの担当に伝えること（その日のうちに）

- 返金メモを、**レジ締めの前に** システムの担当（または店長）に渡します。
- システムの担当が、管理の画面（Desk）で元の伝票から **返品伝票（Credit Note）** を作ります。これでシステムの売上・現金・消費税が戻ります。
- **レジ締めのとき、現金が「予定額」より少なく見える** のは、この返金のぶんが、システムにまだ入っていないからです。返金メモの金額と、差額が合っていれば大丈夫です。メモを店長に見せます。

> **システムの担当へ：** 返品伝票を作ったら、**税額が元の伝票と一致するか確認します。** 伝票の全部を返すときは、元の伝票と同じ税額（符号だけ逆）になります。一部だけを返すときは、返す分の税抜金額から税額を計算するので、何回かに分けて返すと、合計が元の伝票より 1 円少なくなることがあります（多くなることはありません）。

## 5．やってはいけないこと

- 店長の OK なしに、お金を返さない。
- カード・PayPay・楽天ペイで払ったお客様に、現金で返さない。
- 返金メモを書かずに、引き出しを開けて返さない。
- レシートを回収せずに返さない（回収できないときは、その理由をメモに書く）。
- 「レジの画面で返金できる」と、お客様やほかの店員に言わない。

## 6．店で決めること【店長確認待ち：下は案です。決まったことではありません】

1. **現金以外で払ったときの返金**：店長が、支払い会社の端末または管理の画面で操作します。システムには、備考（時刻・金額）を残します。【具体的な手順は、加盟店の契約を確認してから書きます】
2. **返金の OK**：すべて **店長が OK** を出します。金額の下限は設けません。店長が店にいないときは、電話で連絡します。【連絡先の名前と電話番号は、12/4 の社員アカウント確認のときに書きます：＿＿＿＿＿＿＿＿】
3. **一部だけ返すときの税額の 1 円の差**：何回かに分けて返すと、税額の合計が元の伝票より 1 円少なくなることがあります（システムの担当が返品伝票を確認します）。【店長・税理士に確認】
4. **合算して支払い済みの伝票**：店員は店長を呼ぶだけです。システムの担当が、管理の画面で、2 枚の伝票それぞれに返品伝票を作ります。

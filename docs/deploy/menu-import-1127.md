## 2. 浏览器确认（在复制站点上；网址用 `http://ury-menu-<日期>.localhost:8000`）

1. **收银台** `/pos`（レジ担当）：菜单按分类显示；每个商品的名称、图片（有的话）对；点一个有规格的商品，规格和加料对话框的选项、加价对。
2. **价格**：任取 3 个商品，店内和持ち帰り各点一次，对照 Excel 的「税込」两列（店内 10%、持ち帰り食品 8%，酒 10%）。
3. **厨房**：每类商品发到对的厨房（发送后看厨房画面 `/mosaic/<厨房名>`）。没有厨房的商品会提示。
4. **顾客页**（扫码或链接，要先开桌）：只显示「セルフオーダー」是 ○ 的商品；规格、加料、年龄确认（酒）、语言切换。
5. **停售和推荐**：标了停售的不出现，推荐的有标记。
6. **取消**：用过的测试订单取消，不留在站点（站点最后删除，所以不影响，但先走一遍流程）。

## 3. 失败了怎么办

- 计划阶段只读，**什么都不会写**；`✗` 全部列出，按句子改 Excel。
- 应用阶段任何一步出错，**全部撤回**；演练站点上随时可以丢掉重来。
- 价格不是整数（税込 ÷ 1.1 除不尽）：见 `data-pack.md` 的价格一节；**这是业务决定**（税抜整数 / 税込整数），不是格式问题，要当场定。
- 同一道菜店内和持ち帰り的**本体价格不同**：数据包和系统现在不支持，见 2026-11-17 的评估（`launch-plan.md` 里的待决项）。

# 5．困ったとき（全員）　レジの横に貼ります

## まず、お客様が注文できて、お金を払えるようにします。システムを直すのは、そのあとです。

| 見えること | 先にすること | だれに言う |
|---|---|---|
| **お客様のスマホで、二次元コードが開かない** | 店員が注文を取ります。（テーブルのタブレットは使えます）そのテーブルで「セルフオーダー開始」を押したか見ます | 店長 |
| **テーブルのタブレットが動かない** | 画面を下に引っぱって更新します。直らなければ、店員が注文を取ります | 店長 |
| **厨房の画面に注文が来ない** | 口で、または紙に書いて厨房に伝えます。厨房は画面を更新します | レジ担当 → 店長 |
| **レジに「厨房伝票が出ませんでした」と出た** | すぐ厨房に口で伝えます | 店長 |
| **レシートが出ない**（画面に「用紙がありません」「カバーが開いています」「接続できません」と出る） | **下の「プリンターが動かないとき」の順番**でします。急ぐときは手書きの領収書をわたし、あとで印刷し直します | 店長 |
| **引き出しが開かない**（「引き出しが開きませんでした」と出る） | 鍵で開けます。引き出しの線がプリンターにつながっているか見ます。レジ担当は「引き出しを開ける」でもう一度試せます | 店長 |
| **画面の上に赤い帯「サーバーにつながりません」が出た** | Wi-Fi とサーバーの電源を見ます。つながるまで注文と会計はできません。**紙で続けます**（下の「紙で続けるとき」）。つながると、帯は自動で消えます | 店長 |
| **画面が暗くなった・ロックされた** | 触って起こします。充電ケーブルがつながっているか見ます。何回も起きたら、店長に言います（設定がもとに戻っているかもしれません） | 店長 |
| **レジの画面が開かない・とても遅い** | `Ctrl` + `Shift` + `R` で更新します。ほかの端末でログインしてみます | 店長 |
| **全部の画面が開かない（サーバーの故障・停電）** | **紙で続けます。** 下の「紙で続けるとき」を見ます | 店長 |
| **インターネットが切れた** | 店の中のレジ・タブレット・厨房の画面は **そのまま使えます。** お客様のスマホの二次元コードだけ使えません。カードや QR の支払い端末が使えないときは、現金だけにして、お客様に伝えます | 店長 |
| **合計が 1 円ちがう** | 会計分割・会計合算のあとは、1 円変わることがあります。正しい動きです | — |
| **まちがえて注文を送った** | ホールは取り消せません。レジ担当に頼みます | レジ担当 |
| **ボタンが出ない** | 自分の役割ではできないことです。できる人に頼みます | レジ担当・店長 |
| **パスワードを忘れた** | 店長に言います | 店長 |
| **ログインの画面にもどった** | もう一度ログインします。送っていない注文は消えているので、入れ直します | — |

## プリンターが動かないとき（紙が出ない・画面に「接続できません」「応答しません」と出る）

**この順番でします。** 1 つ済んだら、もう一度「印刷」を押してみます。（「接続できません」は電源とネットワークが原因、「応答しません」はプリンターがエラーの状態のとき。どちらも同じ順番です）

1. **ランプを見ます。** プリンターのランプは 3 つです。
   - **電源ランプ（青）**：消えているときは、電源のコードを見ます。**青が点滅していて、エラーランプ（橙）も点いているとき**は、プリンターが止まっています（カバーを開けたあとなど）。**3 の電源の入れ直し**をします。
   - **エラーランプ（「！」マーク、橙）**：点いている・点滅しているときは、エラーの状態です（下の 2 と 3 をします）。紙がないときも、このランプが点きます。
   - **紙ランプ（用紙の状態を示す）**：**点いているときは、用紙がありません（セットされていません）。紙を入れます**（2 をします）。【点滅の意味は未確認です】
2. **カバーと紙を見ます。** カバーがきちんと閉まっているか、紙が入っているか、紙の向きが合っているか（逆だと字が出ません）。カバーを開けたあとは、**閉めてから** もう一度印刷します。
3. **それでもだめなら、電源のコードを抜いて、10 秒待ってから、差し直します。** ランプが落ち着くまで待ってから、もう一度「印刷」を押します。
4. **まだだめなら、店長に言います。** そのあいだは、手書きの領収書をわたします。

**気をつけること**
- 電源を入れ直すと、プリンターの中に残っていた印刷待ちはなくなります。**出なかった伝票は、画面でもう一度「印刷」を押します。**
- カバーを閉めたあとに、**さっきの伝票が出てくる** ことがあります（カバーが開いていたあいだの分がたまっていたため）。同じ伝票が 2 枚出たときは、**1 枚だけをお客様にわたし、もう 1 枚は捨てます**（領収書を 2 枚わたしません）。
- 「接続できません」が何度も出るのに、プリンターの様子は普通のとき：Wi-Fi・ネットワークのケーブルがはずれていないか見ます。

## 紙で続けるとき（全部の画面が開かないとき）

**くわしい手順と様式（注文・領収書・入金メモ）は「6．紙で続ける手順」にあります。** ここは短い版です。

1. **注文：** 紙の伝票に、時刻・テーブル・料理・数・店内か持ち帰りかを書いて、厨房にわたします。
2. **お会計：** 紙の伝票で計算して、手書きの領収書をわたします。支払方法（現金・カードなど）と金額を書いておきます。
3. **紙は全部取っておきます。** 直ったあと、レジ担当がシステムに入れ直します。
4. 店長に、止まった時刻と、動いた時刻を伝えます。

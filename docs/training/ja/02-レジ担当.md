# 2．レジ担当

**できること：** ホールのこと全部 ＋ お会計・会計分割・会計合算・注文の取消・送った料理を減らす・レジ開け・レジ締め
**できないこと：** 売上レポート・アカウントの管理　→ **店長に頼みます**

画面の下に並んでいるボタン：**ダッシュボード ／ レジ ／ テーブル ／ 伝票 ／ ホール ／ 設定**

> 【写真 2-1：レジの画面全体。下のボタンの列】

## 1．レジ開け（毎日、最初にする）

> 【写真 2-2：「レジ開け」の画面。「レジ開け金額」の欄と「レジ開けをする」のボタン】

1. ログインすると「**レジ開け**」の画面が出ます。
2. 引き出しの中の現金を数えます。
3. 「現金」の「**レジ開け金額**」に、その金額を入れます。（ほかの支払方法は 0 のまま）
4. 「**レジ開けをする**」を押します。「レジを開けました」と出たら終わりです。
5. **画面を 1 回タップします。**（お会計の呼び出しの音が鳴るようになります）

- 全部 0 のまま押すと、確認が出ます。本当に 0 なら「**確認してレジ開け**」を押します。
- 「**前回のレジ締めが済んでいない伝票があります**」と出たら：**前の日にレジ締めを忘れています。**
  店長に知らせます。内容を見て、「**内容を確認しました**」にチェックしてからレジ開けをします。
- 「開店チェックリスト」が出たら、チェックして送信します。

## 2．注文を取る

**レジの画面で取る**（画面の下の「レジ」または「テーブル」）

1. 「店内」か「持ち帰り」を選びます。店内はテーブルを選びます。
2. 料理を **1 回クリック** すると、1 つ入ります。
3. 料理を **ダブルクリック** すると、数・メモ（特別なご要望）・サイズ・トッピングを選ぶ画面が出ます。「**注文に追加**」を押します。
4. 「**注文を確定**」を押します。厨房に届きます。（追加のときは「**注文を更新**」）

**ホールの画面で取る**（スマホなど小さい画面のとき）

1. 画面の下の「**ホール**」を押します。ホールと同じ「テーブル」の画面になります。
2. 使い方は「1．ホール」のページと同じです。
3. **お会計・取消・分割・合算は、ホールの画面ではできません。レジの画面に戻ってします。**
4. レジの画面に戻るとき：右上の **人のマーク** を押して、「**レジに戻る**」を押します。
   （送信していない注文があると、確認が出ます。先に送信するときは「作業を続ける」を押します）

**注文する前にテーブルを変えたとき**

- 確定していない注文があるまま、注文のあるテーブルを選ぶと「**未確定の注文があります**」と出ます。
- 「**この席の注文に追加**」：そのテーブルの注文に足します。
- 「**選択を取り消す**」：元に戻ります。

**あとからトッピングだけ足すとき**（ホールの人から頼まれたときも）**：** レジの画面で、同じ料理をダブルクリック → トッピングにチェック →「**トッピングだけを追加する**」にチェック →「注文に追加」→「注文を更新」。

## 3．お会計

> 【写真 2-3：「お会計」の画面。支払方法と金額の欄、「〇〇 を会計」のボタン】

1. 画面の下の「**伝票**」を押して、その伝票を選びます。
2. 「**会計**」を押します。「お会計」の画面が出ます。
3. 「**支払方法**」の欄に、もらった金額を入れます。
4. お釣りが「**お釣り: 〇〇**」と出ます。
5. 「**〇〇 を会計**」を押します。レシートが出て、引き出しが開きます。

**大事なルール**

- **お釣りは現金だけです。** カードや PayPay は、**ぴったりの金額** を入れます。
  多く入れると「お釣りは現金でのみお渡しできます」と出て、進めません。
- **割り勘（何人かで分けて払う）は、分割しません。**
  同じ「お会計」の画面で、**支払方法を 2 つ以上** 入れます。（例：現金 3,000 ＋ カード 2,500）レシートは 1 枚です。
  **全部の支払いを 1 回で入れます。** 1 人ずつ別々に会計することはできません。
- 「収入印紙が必要です」と出たら：現金で 5 万円以上（税抜）です。紙の領収書に印紙を貼ります。

## 4．会計分割（お客様が **別々の伝票・別々のレシート** がほしいとき）

1. 「伝票」でその伝票を選びます。
2. 「**伝票の操作**」→「**会計分割**」を押します。
3. 新しい伝票に移す料理と数を選びます。（元の伝票に 1 つ以上残します）
4. 「**会計分割を実行**」を押します。
5. それぞれの伝票を、別々にお会計します。

- 分割すると、**別々の取引** になります。税金も別々に計算するので、合計が **1 円** 変わることがあります。これは正しい動きです。
- **迷ったら分割しません。** 支払いを分けるだけなら、上の「割り勘」のやり方です。

## 5．会計合算（2 つの伝票を **1 つにまとめて** お会計するとき）

1. 「伝票」で、まとめる先の伝票を選びます。
2. 「**伝票の操作**」→「**会計合算**」を押します。
3. 合算する伝票を選んで、「**会計合算を実行**」を押します。
4. まとめた伝票をお会計します。

- 合算すると、合計が別々のときと **1 円** 変わることがあります。これも正しい動きです。
- やめるとき：「伝票の操作」→「**会計合算を解除**」。

## 6．取消と、料理を減らす

**注文を全部やめる**

1. 「伝票」でその伝票を選びます。
2. 「**注文を取消**」を押します。
3. **理由を入れます。**（入れないと取り消せません）
4. 厨房に「取消」の伝票が届きます。厨房が「確認」を押します。

**料理を 1 つ減らす：** 注文を開いて数を減らし、「注文を更新」を押します。厨房に「一部取消」が届きます。

- **送った注文の、最後の 1 行は消せません。** 全部やめるときは、上の「注文を取消」です。
- 送った料理の **メモは変えられません。** 変えるときは、取り消して、入れ直します。

## 7．レジ締め（毎日、最後にする）

> 【写真 2-4：「レジ締め」の画面。「開始金額」「予定額」「実際の金額」「差額」の列】

1. 全部のお会計が終わったことを確かめます。（「伝票」に未会計が残っていないこと）
2. 右上のメニューから「**レジ締め**」を押します。
3. 引き出しの現金を数えます。カードなどは、端末の集計を見ます。
4. 支払方法ごとに「**実際の金額**」を入れます。
5. 「**差額**」を見ます。0 でないときは、もう一度数えます。それでも合わないときは、店長に伝えます。
6. 「**レジ締めをする**」→「**はい、レジを締める**」を押します。**これは取り消せません。**

- 「**予定額**」＝ レジ開けの金額 ＋ 今日もらった現金 − 渡したお釣り
- 「**前回までの未締め伝票 〇件**」と出ているとき：前の日の分も入っています。店長に知らせます。
- **レジ締めを忘れると、次の日のレジ開けで注意が出ます。**

## 8．画面に注意が出たとき

| 出た文字 | すること |
|---|---|
| **お会計のお呼び出し**（〇〇：お会計をお願いします） | そのテーブルに行きます。または伝票を印刷します |
| **厨房伝票が出ませんでした** ／ 厨房伝票に問題があります | **すぐ厨房に口で伝えます。** そのあと店長に知らせます |
| レジが開いていません | レジ開けをします |
| 前回のレジが締められていません | 「前回のレジを締める」を押して、先に締めます。店長に知らせます |

---
**ホールも兼ねる人は「1．ホール」も読みます。**（テーブルの色、セルフオーダーの開始、お会計伝票の印刷）

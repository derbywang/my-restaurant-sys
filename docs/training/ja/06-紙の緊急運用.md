# 6．紙で続ける手順（全部の画面が使えないとき）　レジの横に置きます

状態：2026-11-17 の第 1 版。**【税理士に確認】と書いてある 3 か所は、税理士の回答が来たら直します。**【＿＿＿】は店で決めて書き入れます。

## 1．いつ使うか

次のどれかで、**レジの画面も、ホールの画面も、厨房の画面も使えない**とき。

- 停電・サーバーの故障・ネットワーク全部の故障
- 5 分待っても直らない（画面を更新しても、別の端末でも同じ）

**1 台だけ使えない、またはプリンターだけ出ない** ときは、この手順ではありません（「5．困ったとき」を見ます）。

**使うと決めたら、最初に：** 店長に電話します。時刻を書きます（「止まった時刻」）。

## 2．用意するもの（置き場所：＿＿＿＿＿＿＿＿＿）

- 注文の紙（下の様式 A）　　- 領収書の紙（下の様式 B）　　- 入金メモ（様式 C）
- ボールペン、時計、電卓、お金を入れる箱（引き出しの鍵）
- 「止まった時刻」と「直った時刻」を書く紙

## 3．注文を取る

様式 A に書きます。**1 テーブルにつき 1 枚**。足すときは同じ紙に書き足します。

| テーブル（または 持ち帰り） | 時刻 | 店内 / 持ち帰り | 料理名 | 数 | メモ |
|---|---|---|---|---|---|
| | | | | | |

- 書いたら、**厨房に紙をわたします**（口でも伝えます）。厨房は紙を見て作ります。
- 持ち帰りの料理には、**「持」** と書きます。（税率が変わります）
- お酒には **「酒」** と書きます。（持ち帰りでも 10% です）

## 4．お会計

1. 料理の値段を足して、**税込** の合計を出します。値段は **メニューの税込の値段** です。
2. **税率ごとに分けて** 足します：
   - 店内の飲食 … 10%
   - 持ち帰りの飲食（食品）… 8%（軽減税率）
   - お酒 … 10%
3. 税額を出します（**税率ごとに 1 回だけ、1 円未満は切り捨て**）：
   - 10% の分 ＝ 10% の税込合計 × 10 ÷ 110
   - 8% の分 ＝ 8% の税込合計 × 8 ÷ 108
   システムも切り捨てです。【税理士に確認】
4. 領収書（様式 B）に書いて、お客様にわたします。**控え（コピーまたは写し）を必ず取っておきます。**

### 様式 B：領収書（お客様用と控えの 2 枚）

| 項目 | 書くこと |
|---|---|
| 店の名前 | ＿＿＿＿＿＿＿＿ |
| 登録番号 | T＿＿＿＿＿＿＿＿＿＿＿＿ |
| 日付 | 年　月　日 |
| 通し番号 | 紙の領収書は **「紙-001」から順番** に（システムの番号とは別） |
| 内容 | 店内飲食 / 持ち帰り食品 / お酒 の別 |
| 10% 対象の合計（税込） | ＿＿＿＿円　（うち税額 ＿＿＿＿円） |
| 8% 対象の合計（税込） | ＿＿＿＿円　（うち税額 ＿＿＿＿円） |
| ご請求の合計（税込） | ＿＿＿＿円 |
| 支払方法 | 現金 / カード / ＿＿＿＿ |

例：店内 1,100 円（10%）と持ち帰り 540 円（8%）→ 10% の税額 100 円、8% の税額 40 円、合計 1,640 円。

- 持ち帰りの食品には、**「軽」または ※** の印をつけます（軽減税率の対象だと分かるように）。【税理士に確認】

## 5．お金の記録（様式 C：入金メモ）

1 件ごとに 1 行書きます。

| 通し番号 | 時刻 | 合計 | 支払方法（現金/カード/…） | 預かり | おつり |
|---|---|---|---|---|---|

- **現金は箱に入れ、カードなどは別に分けて**、あとで合わせます。
- カード・QR の端末が使えないときは、**現金だけ** にして、お客様に伝えます。

## 6．直ったら

1. **「直った時刻」を書きます。** 店長に知らせます。
2. **レジ担当が、紙の注文を 1 件ずつシステムに入れ直します。**
   - 注文を入れて、**コメント欄に「紙-001 / 実際の時刻 19:42」** と書き、実際の支払方法で会計します。
   - ⚠ 入れ直した注文は **厨房の画面に出ます**。入れる前に厨房に言って、**出てきた伝票は「提供」を押して消してもらいます**。【画面の動きは 12/1 以降に実際に確かめます】
   - 入れ直した注文の領収書は、システムでは **印刷しません**。（お客様に紙の領収書をすでにわたしているため、2 枚出さないようにします）【税理士に確認】
3. 全部入れ直したら、**入金メモの合計と、システムの合計を比べます。** 合わないときは、紙の伝票でもう一度数えます。
4. **レジ締め** をします。（紙の分が入ったあとで）
5. **紙は全部取っておきます**（注文の紙、領収書の控え、入金メモ）。保管の期間は税理士に聞きます（インボイスの控えは 7 年）。
